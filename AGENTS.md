# Arketype — contributor and agent guidance

Arketype is a **non-normative design library**. It is not a new Kristal Framework, an authority over existing states, or an operational system.

- Preserve the bundled Local Authoring Kit 3.2.4 command contracts and stable technical identifiers.
- Treat `archetypes/`, `assemblages/`, `design/`, and `arketype.template.json` as descriptive, noncanonical metadata.
- Instantiation must create a new slug and `state_ref`; the owner must ensure uniqueness in the real deployment.
- Never assume permission to publish, activate, access private data, or execute operational procedures.
- Do not copy an external committed knowledge state where an exact pinned reference is required.
- Composition recipes are design plans. Define semantic ownership and interfaces before accepting logical artifacts.
- Run the library tests and Authoring Kit `check` commands; `build-v9` is not publication or factual qualification.
- Update the relevant source JSON, descriptive docs, generated views and tests together when a design changes.
