# Intention et scope

Ce modèle neutre sert à démarrer un Kristal de famille **Univers / œuvres / médias**.

**Forme candidate** : Référents d’univers, œuvres, événements fictifs, manifestations médiatiques et correspondances.

Cas de référence (analogiques, non clonés) : KingKlown MEDIA, univers créatifs, musée.

Aucun fait ou corpus métier n’est prérempli. Définir le domaine réel, les destinataires, les droits et les preuves avant de cristalliser quoi que ce soit.
