# Purpose and scope

This neutral starter workspace illustrates **Casefile / Follow-Up** (`ARK-19`).

**Purpose:** Central record of documents, notes, actions and follow-ups. Employee follow-up, case management and tracked interventions.

**Typical applications:** employee follow-up, HR casefile, case management.

It contains no admitted domain facts, personal data, privileged process authority or normative Logical Contract. Define sources, scope, permissions and ownership for any real instance.
