# Arketype : correspondances rhétoriques Spek

`contracts/spek-rhetorical-guidance.json` propose 57 références candidates
pour les 19 archétypes. Les références sont vérifiées contre le catalogue de
62 templates de Spek (`spek_guidance.py --spek-inventory ...`).

Il s'agit d'un **indice non normatif** pour l'IA éditoriale, jamais d'une
assignation d'assertions, d'une preuve ni d'une autorisation.
